# Alzheimer’s Disease Prediction – Case Study Project
This project was part of an academic assignment focused on exploring early indicators of Alzheimer’s disease using data analysis and basic machine learning. The dataset included 74,283 records with information like age, education, lifestyle habits, and genetic risk factors.
# What I Worked On
1. Cleaned and prepared the data for analysis
2. Explored the data using visualizations to find patterns and trends
3. Built two models – Logistic Regression and Random Forest – to predict Alzheimer’s diagnosis
4. Evaluated the models using accuracy, precision, recall, and ROC-AUC
5. Created a Power BI dashboard to summarize and share the findings in a simple, interactive format
# Tools I Used
Python (Pandas, Matplotlib, Seaborn, Scikit-learn)
Power BI
Data Source: Kaggle – Alzheimer’s Prediction Dataset
# What I Learned
This project helped me get more comfortable working with real-world data and using machine learning to support decision-making. I also learned how to turn data into visuals that others can easily understand. It was a great way to practice both the technical and communication sides of data analytics.
